# Report blueprints

PrimeTwin materials are benchmark/reference. They are not EFESO capability proof, not EFESO delivered results, not account facts, and not institutional EFESO claims.

These modes are recorded for a future report layer. No new engine is implemented in this sprint.

## 1. Account Targeter Brief

A future brief that uses account signals and sanctioned EFESO knowledge to describe where a company is under operational pressure. It must not invent opportunities or treat PrimeTwin estimates as EFESO proof.

## 2. Value Creation / Benchmarker Lens

A future lens that uses PrimeTwin and other benchmarks as reference ranges only, labeled `historical_benchmark` / `potential` / `estimated`, never as captured EFESO savings.
